## <div align="center">🎯 Coding Challenge</div>

<div align="center">
  <h3>Solve This Coding Puzzle!</h3>
  
  ```javascript
  // What will be the output of this code?
  const promise1 = Promise.resolve('First');
  const promise2 = Promise.resolve('Second');
  const promise3 = Promise.reject('Third');
  const promise4 = Promise.resolve('Fourth');
  
  const runPromises = async () => {
    const res1 = await Promise.all([promise1, promise2]).catch(err => err);
    const res2 = await Promise.all([promise3, promise4]).catch(err => err);
    return [res1, res2];
  }
  
  runPromises().then(res => console.log(res));
  ```
  
  <details>
    <summary>View Solution</summary>
    <pre><code>[['First', 'Second'], 'Third']</code></pre>
    <p>Explanation: The first Promise.all resolves with an array of resolved values. The second Promise.all fails because promise3 rejects, so it goes to the catch block which returns just the error string.</p>
  </details>
